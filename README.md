# 心理学十二镜议会

> [打开产品介绍页 / Open the product page](https://yety1113.github.io/psychology-council/)

一个用于个人反思与决策的 Codex 插件。它让十二种经典心理学视角围绕同一问题独立立论、相互质询、钢人化对方，再把真正的分歧交还给用户判断。

它适合讨论拖延、关系、职业选择、自我理解、沟通和价值冲突；不是诊断、治疗、药物建议或危机支持服务。

## 十二面镜子

| 分组 | 代表视角 | 关注点 |
| --- | --- | --- |
| 深层动力 | 弗洛伊德、荣格、伯恩 | 冲突、防御、身份、脚本与重复模式 |
| 行动改变 | 斯金纳、贝克、班杜拉 | 行为后果、自动思维、自我效能与可验证改变 |
| 意义成长 | 罗杰斯、弗兰克尔、马斯洛 | 真实经验、意义、责任、需要与成长 |
| 关系系统 | 阿德勒、鲍尔比、萨提亚 | 归属、依恋、安全感和家庭沟通系统 |

人物都是基于公开理论构建的“观点代理”。插件不会冒充历史人物，也不会编造他们的原话。

## 工作方式

1. 先做安全分流并明确真正需要理解或决定的问题。
2. 十二镜快速扫描，呈现互相冲突而非同质化的解释。
3. 用户选择 2–4 位代表进入议会。
4. 各视角独立立论，说明证据、盲点与反证条件。
5. 通过钢人化、反驳、交换立场和价值探索推进讨论。
6. 只有用户要求总结时，才形成暂定判断和低风险行动实验。

## 插件工具

仓库包含一个本地 MCP 服务，用于：

- 在当前进程维护结构化议会状态；
- 渲染议会面板；
- 预览拟保存内容；
- 经用户明确确认后，保存去标识化 Markdown 记录；
- 经再次确认后删除指定记录。

默认不建立跨会话心理档案，也不保存原始聊天。持久化保存必须经过预览与明确确认。

## 安装

克隆仓库后，在仓库根目录运行：

```sh
codex plugin marketplace add .
codex plugin add psychology-council@psychology-council-github
```

安装完成后开启一个新任务，使插件和本地工具生效。运行环境需要 Python 3。

## 快速开始

```text
使用 psychology-council 讨论：我为什么总在重要事情上拖延？
```

你也可以在过程中控制议会：

- `选人：贝克、班杜拉、伯恩、萨提亚`
- `先钢人化，再反驳`
- `交换立场`
- `探索价值冲突`
- `引入现代证据`
- `显示议会面板`
- `总结`

## 安全边界

- 不给出精神疾病诊断、药物建议或治疗承诺。
- 不把童年、依恋、家庭或潜意识推演写成既定事实。
- 不用多数票替用户决定价值问题。
- 当出现即时安全风险时，应停止角色讨论并寻求现实中的紧急或专业支持。

本仓库目前未声明开源许可证。公开可见不等于自动授予复制、修改或再分发许可。
